아이디어를 플레이할 수 있는 결과물로 만드는 기획자

11년간 모바일과 PC 게임의 시스템, 전투, 레벨을 기획했습니다. 최근에는 Claude Code로 기획 데이터 검증 툴과 로그 분석 툴을 직접 만들었고, 기획팀뿐 아니라 QA와 사업팀도 이 툴을 씁니다.

개인 프로젝트로는 직접 기획한 보드게임 Extraction B (가칭)를 Claude Code와 함께 실제 작업 18일 만에 정식 한 판을 문제없이 끝까지 플레이할 수 있는 3D 웹 게임으로 만들었습니다. 게임과 데모는 모두 각 페이지 안에서 바로 실행해 볼 수 있습니다.

역량한 일위치
아이디어를 플레이어블로 만들기직접 쓴 보드게임 규칙서를 실제 작업 18일 만에 정식 한 판을 문제없이 끝까지 플레이할 수 있는 3D 웹 게임으로 만듦. 첫 플레이어블은 9일째AI 프로젝트
AI와 역할을 나눠 프로젝트 진행규칙과 밸런스 결정, 작업 범위 판단은 직접 하고, 구현과 반복 실험은 Claude Code에 맡김. 자주 조정할 부분은 툴(맵 편집기)을 만들어 직접 수정. 단계 계획과 승인, 결정 기록(136건)으로 진행 관리AI 프로젝트
숫자와 플레이로 검증하고 결정AI 대전 150판 보고서, 처음 하는 AI 테스터, 직접 플레이로 규칙을 고치고, 새 아이디어는 두 버전을 나란히 만들어 A/B로 비교AI 프로젝트
AI 결과물의 정확성 확인버그처럼 보이는 보고와 이상한 지표를 엔진 기록, AI 판단과 대조해 원인을 가림. 실무 툴에서도 집계 오류와 데이터 착시를 찾아 수정AI 프로젝트, 포트폴리오
생성형 AI 도구의 실제 업무 활용Claude Code로 데이터 검증 툴, 로그 분석 툴, 자체 MCP 서버 2개를 만들어 팀이 함께 사용포트폴리오
개발이 참조할 기획 산출물시스템 기획서와 데이터 흐름도를 쓰고, 조작해 볼 수 있는 프로토타입으로 먼저 검증포트폴리오

AI 프로젝트를 진행하는 관점

아이디어는 말이나 문서로만 있을 때보다 직접 해 볼 수 있을 때 판단이 훨씬 빨라진다고 생각합니다. AI 도구로 플레이어블을 만드는 속도가 빨라진 만큼, 무엇을 만들지 정하고, 결과가 맞는지 확인하고, 다음에 무엇을 고칠지 결정하는 일이 더 중요해졌습니다.

Extraction B (가칭)에서도 구현은 AI에 맡기되 결정은 직접 했고, AI가 낸 결과는 기록과 대조해 확인했습니다. 회사 프로젝트에서도 같은 방식으로, 빠르게 만들어 보고 숫자와 플레이로 판단하는 흐름을 팀에 만들고 싶습니다.
